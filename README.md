## Projects

### Smart Home IoT System with Human Detection

A smart home project using **ESP8266**, **ESP32-CAM**, sensors, MQTT, and Blynk.

- Controlled home devices remotely using ESP8266
- Used ESP32-CAM for human detection
- Applied YOLOv3-based object detection for detecting human presence
- Used MQTT and HiveMQ Cloud for device communication
- Integrated DHT11 and IR modules for environmental monitoring
- Built a simple mobile interface with Blynk

**Technologies:** `ESP8266`, `ESP32-CAM`, `MQTT`, `HiveMQ`, `Blynk`, `YOLOv3`, `DHT11`

---

### Line Following Robot using STM32 with Bluetooth

A small embedded project for learning STM32 motor control and communication.

- Built a line-following robot using STM32 and IR sensors
- Implemented motor control with PWM
- Used UART to communicate with a Bluetooth module
- Tuned parameters to improve movement stability

**Technologies:** `STM32`, `C/C++`, `PWM`, `UART`, `Bluetooth`, `IR Sensors`
